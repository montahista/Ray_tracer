# RayTracer

A software ray tracer built from scratch in C++ with OpenGL/FreeGLUT.

## Features

- Ray–Sphere and Ray–Plane intersection
- Phong shading (Ambient + Diffuse + Specular)
- Hard shadows, Reflection, Refraction
- External scene file format (.dat)

## Build

g++ src/\*.cpp -o RayTracer -lfreeglut -lopengl32 -lglu32 -lgdi32 -lpthread

## Run

RayTracer.exe scenes/file1.dat
